Bem-vindo ao SaguiOS!
=====================

O SaguiOS é um sistema operacional pequeno, escrito do zero por uma IA,
para PCs x86 de 32 bits. Ele roda inteiro na memória: o pendrive de boot
só é lido uma vez, quando o computador liga.

Como usar o terminal
--------------------

O terminal é o sagsh, um programa comum. Digite um comando e aperte Enter.
Cada comando tem também um apelido em português:

  ajuda              lista todos os comandos (ajuda <comando> explica um)
  ls / listar        mostra os arquivos da pasta atual
  cd / entrar        entra numa pasta (cd .. volta)
  cat / ver          mostra o conteúdo de um arquivo
  echo / eco         escreve um texto (echo oi > tmp/a.txt grava num arquivo)
  cp, mv, rm         copia, move e apaga arquivos
  mkdir, rmdir       cria e remove pastas
  wc / conta         conta linhas, palavras e letras
  ps / processos     mostra os programas rodando
  kill / matar       encerra um programa
  mem, data, sobre   memória, data e hora, e sobre o sistema
  contador 10 &      conta 10 segundos em segundo plano
  falha              faz um erro de propósito (só o programa morre)
  limpar, reiniciar, sair

Truques: comando > arquivo, comando >> arquivo, comando < arquivo,
comando1 | comando2 (ex.: ls bin | conta), seta para cima repete
comandos, Tab completa nomes.

Arquivos para ler
-----------------

  sobre.txt              como o sistema foi feito
  historia/linux.txt     um pouco da história do Minix, do Linux e do GNU
  historia/saguios.txt   o diário deste projeto
  arte/sagui.txt         o nosso mascote

Exemplos para compilar e rodar dentro do sistema
-------------------------------------------------

  csagui build -o /tmp/tabuada /c/tabuada.c   compila C dentro do SaguiOS
  /tmp/tabuada                                 executa o programa gerado
  gosagui build -o /go/sobre /go/sobre.go      compila Go dentro do SaguiOS
  lua /lua/gui.lua                             janela com botão, caixa e lista
  lua /lua/relogio.lua                         relógio de tempo ligado
  csagui build -o /tmp/sudoku /jogos/sudoku.c  compila o Sudoku no sistema
  /tmp/sudoku                                   joga (também /jogos/pong.c,
                                                 /jogos/tetris.c)

O Lua também tem a biblioteca "gui" (janela, botão, caixa de texto, lista,
diálogos), usada pelos exemplos acima. Os programas em C usam o mesmo kit em
userland/inc/gui.h. Veja a pasta /c, /go, /lua e /asm.

Os arquivos que você criar em /tmp ficam na memória e somem ao desligar.
Para guardar de verdade, use um pendrive de dados (comando montar).
